# بوابة الخدمات الموحدة — نموذج PHP تجريبي

بوابة عربية RTL أصلية لخدمات مجتمعية خيالية. المشروع مستقل وغير رسمي، ولا ينسخ هوية أو محتوى أي جهة أخرى.

## المتطلبات والتشغيل

- PHP 8.1 أو أحدث
- لا توجد قاعدة بيانات أو حزم خارجية مطلوبة

من داخل مجلد المشروع في Cursor شغّل:

```bash
php -S localhost:8000 router.php
```

ثم افتح `http://localhost:8000` في المتصفح.

## بيانات الدخول التجريبية

- اسم المستخدم: `demo`
- رمز الدخول: `2468`

أي بيانات أخرى تُرفض، ولا يُحفظ رمز الدخول في التخزين.

## مسار التجربة

- `/` تسجيل الدخول التجريبي
- `/register` إنشاء ملف عرض بأربع خطوات آمنة
- `/access-help` استعادة بيانات العرض دون بريد أو OTP
- `/portal` لوحة الخدمات الخيالية
- `/service?code=community-event` تفاصيل خدمة ورسوم وهمية
- `/user-type` اختيار فرد أو منشأة أو زائر
- `/request` إدخال الاسم التجريبي والخدمة والمدينة والموعد والملاحظات الاختيارية
- `/details` تفاصيل الخدمة والرسوم التقديرية الوهمية
- `/review` مراجعة البيانات والتأكيد أنها تجريبية
- `/success` نجاح الطلب ورقم مرجعي وهمي

## الخصوصية والسلامة

- تسجيل الدخول يقبل بيانات العرض المعلنة فقط، ولا توجد حسابات أو كلمات مرور حقيقية أو OTP.
- لا توجد حقول هوية أو بيانات دفع أو بطاقات.
- لا توجد API أو تكاملات أو Telegram أو لوحة إدارة أو تتبع.
- تحفظ مسودة الطلب في `sessionStorage` داخل تبويب المتصفح فقط.
- تمسح المسودة تلقائيًا عند الوصول إلى صفحة النجاح.
- استخدم بيانات خيالية فقط؛ الموقع يعرض شارة ثابتة بهذا التنبيه في جميع الصفحات.
